## 5. Post-deploy on the prod server
```bash
composer dump-autoload -o
php artisan migrate --force          # runs the 2 new tables
php artisan config:cache && php artisan route:cache && php artisan view:clear && php artisan cache:clear
php artisan gamification:backfill    # one-time, quiet — awards existing prod users their earned level
```
Then monitor `storage/logs/laravel.log` 10–15 min.
