**What:** The 7-key return shape `['success' => true, 'created' => true, 'entity_type' => ..., 'entity_id' => ..., 'name' => ..., 'persisted_fields' => array_keys(array_diff_key($payload, ['user_id' => null])), 'message' => ...]` is repeated verbatim 16 times.
