# Fynla v0.9.0 Patch Notes

**Released:** 15 March 2026
**Previous version:** v0.8.3

---

## Headline

The Fynla Brain has been upgraded from static rule-based advice to a dynamic, data-aware decision engine. Every module now validates your data before running analysis, every tax value is centralised, and recommendations are transparent — you can see exactly why each one was made.

---

## What's New

### Fynla Brain Decision Engine

The core engine powering all financial analysis has been completely rebuilt.

**Data Readiness Gates**
All five modules now check your data is complete before running analysis. If something is missing, you'll see exactly what's needed with a direct link to add it. No more misleading results from incomplete information.

**Investment Pipeline**
A new 9-phase engine analyses your investments systematically:
1. Safety checks and emergency fund validation
2. Life event impact assessment
3. Goal mapping and progress tracking
4. Contribution waterfall — prioritises where your money should go (Lifetime ISA → ISA → Pension → Premium Bonds → General Investment Account)
5. Transfer scans — identifies 13 types of optimisation opportunities
6. Spouse optimisation — 7 strategies for couples (Capital Gains Tax sharing, ISA coordination, pension prioritisation)
7. Conflict resolution — removes duplicates and ranks by impact

**107 Recommendation Triggers**
Recommendations are now driven by database triggers instead of hardcoded rules:
- 41 savings triggers (emergency fund, ISA, rate comparison, Personal Savings Allowance, Financial Services Compensation Scheme exposure)
- 28 protection triggers (employer benefits, policy trust status, expiry alerts, income protection)
- 18 retirement triggers (salary sacrifice, auto-enrolment, enhanced annuity, care costs)
- 14 investment triggers (fees, rebalancing, tax loss harvesting, bonds)
- 6 tax optimisation triggers

**Centralised Tax Engine**
Every UK tax value — Nil Rate Band, ISA allowance, Pension Annual Allowance, Personal Savings Allowance, Capital Gains Tax exemption, and more — is now sourced from a single service. When HMRC changes rates, one update applies everywhere.

---

### Savings Module

- **Personal Savings Allowance analysis** — see how much tax-free interest you have left and whether you're at risk of breaching it
- **Financial Services Compensation Scheme exposure** — warnings when your savings at one banking group exceed the £85,000 protection limit
- **Smart emergency fund targets** — 9 months if self-employed, 6 if employed, 3 if retired
- **Daily alerts** — maturity reminders at 90, 30, and 7 days; rate expiry notifications; year-end ISA allowance warnings

### Estate Planning

- **2027 pension amendment** — see how your Inheritance Tax liability changes when pensions become part of your estate from April 2027, with side-by-side current vs amended projections
- **14-year gift rule** — historical chargeable lifetime transfers now correctly reduce the Nil Rate Band available for later gifts
- **Enhanced life insurance checks** — warnings for policies not held in trust, single-life policies for married users, and term policies approaching expiry
- **Trust projections** — year-by-year growth trajectory for planned trust settlements

### Retirement

- **Salary sacrifice analysis** — see how much National Insurance you and your employer save, with warnings for sacrifices that push you below the Personal Allowance
- **Auto-enrolment compliance** — checks whether you're meeting the minimum 8% total contribution (3% employer, 5% employee)
- **Enhanced annuity assessment** — if you smoke or have health conditions, your annuity rate could be significantly higher

### Protection

- **Employer benefits** — death-in-service, group income protection, and group critical illness cover are now deducted from your coverage gaps
- **State benefits offset** — Statutory Sick Pay correctly calculated at £118.75/week for up to 28 weeks (excluded for self-employed)
- **Descriptive ratings** — coverage status shown as Excellent, Good, Fair, or Critical instead of numeric scores

### Plan Isolation

Individual module plans now contain only their own recommendations. Cross-module optimisation — pension contributions for the higher-rate partner, savings allowance sharing, marriage allowance — only appears in the Holistic Plan where everything is coordinated together.

## Bug Fixes

### Login Verification (Critical)
The verification code entered after login was failing with a 422 error. The root cause was challenge tokens stored in the application cache — when the cache driver resolved to in-memory only, tokens were lost between requests. Challenge tokens are now stored in the database, making login reliable regardless of cache configuration.

### Security
- User ID removed from pre-authentication API responses to prevent user enumeration
- Sensitive fields (passwords, tokens, API keys) filtered from preview mode responses

### Plan Endpoints
- Investment plan no longer crashes for personas with Lifetime ISA goals (was passing an array to a number formatter)
- Retirement plan no longer crashes for already-retired users without a retirement profile
- Plan action priorities correctly handle both string and integer values

### Investment Plan Quality
- All 15 actions now have meaningful titles and descriptions instead of generic "Recommendation" placeholders
- Pension, savings allowance, and marriage allowance actions removed from the individual investment plan (moved to holistic plan only)

### Property Page
- Property page no longer shows a blank content area after the API response format was standardised
