# Dashboard screenshots recovered from git history

Every image in this repository's history whose path contains "dash", pulled straight
out of the git object store and filed under the month its commit landed. Images long
since deleted from the working tree are here too — the blobs never went anywhere.

Two kinds of image are mixed together, and the filename tells you which:

- **Live captures** — `Jan5Updates__Screenshots__…`, `March__March20Updates__…`,
  `docs__sprint-0-verification__…`, `codex__evidence__…`: the app as it actually looked.
- **Design markups** — `public__images__References__…`: dashboard screenshots CSJ annotated
  to mark up layout problems. `Finco-Dashboardexample.webp` is a competitor's dashboard,
  kept for reference.

**The October 2025 file is not a dashboard.** Four Playwright tests (protection, savings,
investment and retirement dashboards) failed on the same day, and all four saved the same
screenshot — the registration page, still branded "FPS", because the run was never logged
in. Git stores one blob for the four identical files, so this folder holds one copy. It is
kept as the earliest surviving capture in the repository, not as a dashboard.

**Months with no dashboard images at all:** February, May, June and August 2026. Those
months captured chat, checkout, marketing templates and bug reports instead. Anything
named differently — a dashboard screenshot called `01-after-onboarding.png`, say — is not
picked up by this search.
