# Package 3 Dev Deployment Note — 18 July 2026

## Status

Ready for **dev only** after draft PR #633 is approved and merged. Nothing in this note authorises a production deployment, production request or production migration.

## Server changes

- Native session persistence: two additive migrations create `native_device_sessions` and `native_refresh_tokens`.
- Native session exchange, refresh, show and revoke services/routes.
- Additive native device-label middleware, input sanitisation and preview-write protections.
- Existing desktop and `/m` authentication contracts remain in place.

## Dev deployment sequence

1. Merge PR #633 to `dev` only after its required evidence/approval gate.
2. Update the dev server checkout to that exact `dev` commit.
3. Run `php artisan migrate --force` on dev; never use `migrate:fresh` or `migrate:refresh`.
4. Run the repository's mandatory full `php artisan db:seed --force` after the migration.
5. Clear the normal Laravel application/config caches used by the dev deployment process. Do not introduce `route:cache`.
6. Confirm migration status and exercise the native session/authentication smoke against dev.
7. Use the installed Google Chrome through the Chrome connector for any `/m` browser acceptance. Never use Chromium or the in-app browser.
