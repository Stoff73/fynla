## Backfill commands (run AFTER migrate)

If existing data has drifted `outstanding_mortgage` values, reconcile them:

```bash
# Reconciles all properties.outstanding_mortgage from canonical mortgages sum
php artisan properties:backfill-outstanding-mortgage

# Backfills Pass 4 Property derived columns
php artisan properties:backfill-derived-columns

# Backfills Pass 5 Mortgage derived columns
php artisan mortgages:backfill-derived-columns
```

All three are idempotent + chunked (200 rows per batch) + use `forceFill+saveQuietly` to avoid event storms.

## Rollback plan

If migrations break csjones, the down() methods are inverse-clean:

```bash
php artisan migrate:rollback --step=5
php artisan db:seed --force
```

This drops the 5 new tables/columns. Source code stays as-is — the migration rollback is sufficient because the new derived columns are nullable.

If `properties.outstanding_mortgage_calculated_at` was already populated by recalc when rolling back, that's fine — the column simply disappears.
