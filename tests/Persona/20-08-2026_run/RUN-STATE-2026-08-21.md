## 8. Traps a cold reader will hit

- **Read working notes from the bottom.** Corrections are appended, never applied.
- **`git status --porcelain` undercounts.** It collapses untracked files in new
  directories; use `-uall` or you will accuse the agents who wrote tests.
- **`ops/branches/` is empty and is not where branch documents live.** They are at
  `workforce/branches/<type>/`. The empty directory resolves if you read the path
  relative to `ops/`, so the check succeeds and the answer is wrong.
- **`claimed` with no code is correct**, not drift. The coordinator claims at dispatch.
- **`!` and `DEPR` in Pest output are not failures.** Read the summary line.
- **Never run bare `php artisan migrate`** on the shared dev database — it applies every
  other agent's pending migration. Use `--path`.
- **The board is the only shared record of who holds what.** An agent's report can be
  stale by the time you read it.
