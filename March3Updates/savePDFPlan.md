# Fix Print/Save PDF Format for Estate Plan

## Context

The "Print / Save PDF" button opens a new browser window with custom HTML generated by `planPrintMixin.js`, then calls `window.print()`. The estate plan was recently rewritten with structured executive summary, personal information section, full IHT calculation table, gifting schedules, and estate-specific what-if — but the print mixin wasn't updated. The PDF output currently shows a blank executive summary (no `narrative` field), no current situation content (no estate branch), no personal information, and basic actions without gifting detail.

## File to Modify

| File | Change |
|------|--------|
| `resources/js/components/Plans/Shared/planPrintMixin.js` | Add estate detection + 8 new builder methods + conditional branching in `buildPlanHtml()` |

No other files need changes. Non-estate plans remain untouched.

---

## Implementation

### 1. Add Utility Methods

```
isEstatePlan(plan)        — Returns true if plan has estate-specific data (greeting, personal_information, or iht_summary)
fmtPercentage(val)        — Formats number as "X%"
```

### 2. Add Estate CSS to Style Block

Add to the `<style>` in `buildPlanHtml()`:
- `.iht-table` — Full-width IHT table at 10px font
- `.iht-owner-header` — Bold row for "David's Assets" etc.
- `.iht-asset-row td:first-child` — 20px left indent for individual assets
- `.iht-subtotal`, `.iht-total` — Bold summary rows
- `.iht-allowance` — Light green background for allowance rows
- `.iht-liability` — Red text for IHT liability
- `.metric-grid`, `.metric-card` — Flex grid for supplementary cards
- `.guidance-list` — Numbered list for step-by-step guidance

### 3. Modify `buildPlanHtml()` — 5 Conditional Injection Points

| Point | Current | Estate Branch |
|-------|---------|---------------|
| Executive Summary | `summary.narrative` | `buildEstateExecutiveSummaryHtml(summary)` |
| After Exec Summary | (nothing) | `buildEstatePersonalInformationHtml(plan.personal_information)` |
| Current Situation | `buildCurrentSituationHtml()` | `buildEstateCurrentSituationHtml()` |
| Actions | `buildActionsHtml()` | `buildEstateActionsHtml()` |
| What-If | `buildWhatIfHtml()` | `buildEstateWhatIfHtml()` |

All behind `isEstatePlan(plan)` guard. Conclusion section works as-is.

### 4. `buildEstateExecutiveSummaryHtml(summary)`

Renders: greeting → opening (optional) → introduction → Key Actions table (Action | Priority badge) → closing paragraph.

Data: `{greeting, opening?, introduction, actions_summary: [{title, priority}], total_actions, closing?}`

### 5. `buildEstatePersonalInformationHtml(info)`

Renders 2×2 grid using `display: flex; flex-wrap: wrap`:
- **Personal Details**: Full Name, Date of Birth, Age, Marital Status
- **Family**: Spouse, Children
- **Financial Overview**: Gross Income, Net Income, Annual Expenditure, Disposable Income (annual/monthly)
- **Estate Profile**: Estimated Age at Death, Years to Planning Horizon, Inheritance Tax Status, Has Will

Data: `{full_name, date_of_birth, age, marital_status, spouse_name, children[], gross_income, net_income, annual_expenditure, disposable_income, monthly_disposable, estimated_age_at_death, years_to_death, marital_status_iht, has_will}`

### 6. `buildEstateCurrentSituationHtml(situation)` — Most Complex

Renders:

**A. Flat IHT Calculation Table** (all rows visible, no expand/collapse):
- 3 columns: Asset/Liability | Now | Projected at Age X
- Per-owner asset rows (user, spouse if married): owner header → individual assets with type prefix and joint labels → owner subtotal
- Gross Estate total row
- Per-owner liability rows: owner header → mortgages (with property address) → other liabilities → owner subtotal
- Total Liabilities row
- Net Estate row
- Allowances section: Nil Rate Band (individual + transferred for widowed), Residence Nil Rate Band (individual + transferred), Total Allowances
- Taxable Estate row
- Inheritance Tax Liability row (red)
- Effective Rate row
- Messages below: iht_rate_message, nrb_message, rnrb_message

Data sources:
- `situation.iht_summary.current/projected` — totals
- `situation.assets_breakdown.user/spouse` — per-owner assets with `{property, investment, cash, business, chattel}` arrays of `{name, value, projected_value, ownership_label}`
- `situation.liabilities_breakdown.user/spouse` — per-owner `{mortgages, other_liabilities}` arrays

**B. Supplementary Cards** (flex grid):
- Asset Breakdown: liquid / semi-liquid / illiquid
- Life Cover (conditional): cover in trust / not in trust / total policies
- Charitable Giving (conditional): current %, threshold, shortfall, potential saving

### 7. `buildEstateActionsHtml(enabledActions, disabledActions)`

For each enabled action, renders (no toggle switches in print):
- Number + title + priority badge + category
- Description
- Estimated impact (green, if present)
- Affordability indicator (if `action.affordability`): green/red badge with monthly premium
- Funding source (if present): gray box with note + liquid assets
- **PET gifting schedule** (if `category === 'pet_gifting'`): table with Year | Gift Amount | Inheritance Tax Reduction | Exempt After Year
- **Annual gifting detail** (if `category === 'annual_gifting'`): 4-cell grid — Annual Amount | Over X years | Total Gifted | Inheritance Tax Saved
- **Guidance steps** (if `action.guidance?.steps`): numbered list + timeframe + professional advice

Disabled actions: simple list (same as existing).

### 8. `buildEstateWhatIfHtml(whatIf)`

Side-by-side comparison table (NOT bar chart):

| Metric | Current Position | With Actions |
|--------|-----------------|--------------|
| Inheritance Tax Liability | currency (red) | currency (red) |
| Effective Tax Rate | percentage | percentage |
| Estate to Beneficiaries | currency | currency (green) |
| Total Mitigation Savings | — | currency (green) |

Data: `{current_scenario: {iht_liability, effective_tax_rate, estate_to_beneficiaries}, projected_scenario: {iht_liability, effective_tax_rate, estate_to_beneficiaries, total_mitigation_savings}}`

## Design Compliance

| Rule | How Addressed |
|------|---------------|
| XSS prevention | All dynamic values through `escapeHtml()` |
| Currency formatting | All monetary values via `fmtCurrency()` |
| No amber/orange (Rule 9) | Badges use red/blue/gray/green only |
| No acronyms (Rule 10) | "Inheritance Tax", "Nil Rate Band", "Residence Nil Rate Band" spelled out |
| British spelling | "Personalised", "Optimisation" etc. |
| Self-contained HTML | All styles in embedded `<style>` block |
| Other plans unchanged | All new code behind `isEstatePlan()` guard |
