# UK Tax Configuration 2026/27

**Tax Year:** 6 April 2026 - 5 April 2027
**Status:** Ready for implementation into `TaxConfigurationSeeder`
**Prepared:** 3 April 2026
**Sources:** GOV.UK, HMRC, DWP, NS&I — links at end of document

---

## Implementation Notes

### Dynamic Tax Year Switching

On 6 April 2026, the app should automatically use the 2026/27 configuration. The `TaxConfigurationSeeder` should:

1. Add a new `getTaxConfig202627()` method
2. Set `is_active = true` for 2026/27 (and `false` for 2025/26)
3. Update the `$taxYears` array in `run()` to include `'2026/27'`
4. Update hardcoded references to `'2025/26'` in the seeder's activation logic

### Files to Update

| File | Change |
|------|--------|
| `database/seeders/TaxConfigurationSeeder.php` | Add 2026/27 config, set as active |
| `app/Constants/TaxDefaults.php` | Update fallback values for 2026/27 |
| `resources/js/constants/taxConfig.js` | Update frontend fallback values |

### Key Changes from 2025/26

| Area | Change | Old | New |
|------|--------|-----|-----|
| **Dividend tax ordinary rate** | +2pp | 8.75% | **10.75%** |
| **Dividend tax upper rate** | +2pp | 33.75% | **35.75%** |
| **BADR/Investors' Relief rate** | +4pp | 14% | **18%** |
| **APR/BPR reform** | New £2.5m cap | 100% unlimited | **100% to £2.5m, 50% above** |
| **AIM shares BPR** | Halved | 100% | **50%** |
| **State pension** | +4.8% | £230.25/week | **£241.30/week** |
| **NLW (21+)** | +4.1% | £12.21/hr | **£12.71/hr** |
| **Child benefit eldest** | +3.8% | £26.05/week | **£27.05/week** |
| **SSP** | Increased | £118.75/week | **£123.25/week** |
| **Premium Bonds prize rate** | Cut | 4.4% → 3.6% | **3.3%** |
| **UC LCWRA (new claims)** | Halved | £416.19 | **£217.26** |
| **Two-child limit** | Lifted | 2 children max | **All children** |
