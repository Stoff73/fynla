### Three gates were silently no-oping on this machine

`.claude/settings.json` points every hook at `/Users/CSJ/Desktop/fynla/.claude/hooks/`,
and each script also opens with `cd /Users/CSJ/Desktop/fynla`. On Windows both fail,
so `tax-hardcode-check`, `design-lint` and `m-parity-check` have been exiting 0
without running. They were re-pointed at this worktree and executed for real.

`design-lint`'s Rule 15 check additionally shells out to `python3`, which on this
machine is the Microsoft Store stub — it errors, the failure is swallowed by
`2>/dev/null || true`, and the emoji check returns empty. **That check has been a
false pass here regardless of the path.** Re-implemented in PHP.

`npm run lint` and `npm run lint:policy` diff `HEAD^...HEAD`. With work uncommitted
they report "no changed files" — a vacuous pass. Both were re-run against the
working tree.

### Rule 15 — four violations found in this item's own write-up

The re-implemented check caught four banned glyphs in `W-0001.md` itself: a person
silhouette, a rightwards arrow (`00-precedence.md` §15 lists arrows explicitly), a
target and a graduation cap. All were quotations of existing UI, but Rule 15 covers
markdown and applies to new work with no grace period. Rewritten as prose; the
check now returns clean across all 165 added lines.
