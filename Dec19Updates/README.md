## Key Changes Summary

### Protection Module (v0.4.1)
- SSP (Statutory Sick Pay) integration in adequacy scoring
- Redesigned policy cards with unified modal
- Improved adequacy analysis display

### Trusts Module
- Party information display (trustees, beneficiaries, settlor)
- Trust type badges and value formatting
- Enhanced trust overview cards

### Tax & Income
- Consolidated earned income card (employment + self-employment + rental + pension)
- Pension contribution deduction from employment income before tax
- Separate cards for dividend/trust/interest income (different tax rates)
- Fixed pension contribution calculations in pension cards
- Removed 6 unused legacy pension panel components

### Retirement
- Pension and trust income display for retired users
- Employer matching limit field for DC pensions
- Calculate contributions from percentages (not just fixed amounts)
- 4.7% sustainable draw rate for income replacement calculations
