Did you know?
If you died or became seriously ill tomorrow, could your family keep the house? With a £245,000 mortgage and 2 dependents, protection insurance isn't optional — it's the foundation your family's security stands on.
Why we ask this
By entering your existing policies, we can run a gap analysis — comparing what you have against what your family would actually need. We calculate the shortfall using your mortgage, income, and dependents.
How this fits your journey
At your stage, the three critical covers are life insurance (clears the mortgage), critical illness (lump sum if diagnosed), and income protection (replaces salary if you can't work). We'll flag any gaps on your dashboard.

Key Points

  • Same fields, same CSS classes — every input uses the existing input-field class or the inline Tailwind pattern (border-horizon-300 rounded-lg focus:ring-violet-500)
  • Same validation, same API — the form's handleSubmit and $emit('save') patterns are unchanged
  • Rendered inline, not as modal — in onboarding context, the OnboardingStep wrapper renders the form inline (left column) instead of inside a modal overlay. The component doesn't know or care.
  • Stage-filtered fields — student PersonalInfo hides address/occupation/health. Mid-career PolicyForm shows all fields. The v-if="isFieldVisible('fieldName')" wraps existing field blocks.
  • Stage-coloured education — student sidebar uses violet gradient, mid-career uses raspberry. Quick stat references the user's actual data (£245k mortgage, age 22).
  • Product type ordering — SaveAccountModal reorders the <optgroup> to show student-relevant types first. Same options, different default order.
