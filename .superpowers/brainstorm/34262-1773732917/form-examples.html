  • PersonalInformation is the main gap — currently NOT used in onboarding (separate PersonalInfoStep.vue exists). Needs context prop added + field visibility logic
  • The context="onboarding" prop controls field visibility via lifeStageConfig.formFields
  • In context="standalone" (profile page, module pages), ALL fields are always shown — no hiding
  • Existing conditional logic within each form (ISA fields, life policy types, etc.) is completely untouched
