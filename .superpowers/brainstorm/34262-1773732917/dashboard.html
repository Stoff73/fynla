Dashboard Design Rules

  • Journey progress hero — always at the top. Shows greeting, stage name, completion %, progress bar, and next step CTA with educational context
  • Stage-curated cards — defined in lifeStageConfig. Student gets 2×2 (budget, loan, savings, actions). Mid-career gets 3×2 (net worth, protection, mortgage, pensions, investments, actions)
  • Dynamic growth — if a student adds a property, a Property card appears automatically. If they add a pension, a Retirement card appears. The dashboard grows with them
  • Stage colour theming — progress bar and accents use the stage colour (violet for student, raspberry for mid-career)
  • Cards only show if data exists — no empty "You haven't added investments yet" cards cluttering the view
  • Actions card always present — even with minimal data, the system can recommend next steps
  • Mobile — single column, journey hero stays, cards stack vertically, same content
