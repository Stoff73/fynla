Design Notes

  • Meandering SVG path — dashed line winds between nodes like a trail on a map, alternating up and down
  • Nodes glow and fade — first node has a glow, later nodes gradually fade, showing progression
  • Gradient path — violet fading to green, from start to destination
  • Tap/hover a node — expands the detail card below the map with the full educational description
  • Green destination — the finish point is "Your Dashboard", making it clear where the journey leads
  • During onboarding — this map appears as a compact progress indicator at the top, completed nodes turn green with ticks, current node pulses
  • Mobile — SVG scales responsively; detail card always visible below; nodes are tap targets
