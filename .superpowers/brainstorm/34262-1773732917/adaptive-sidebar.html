How It Works

  • Stage badge under logo — shows current journey name and age range in the stage colour
  • Journey progress bar — always visible, shows onboarding completion %
  • Primary items — defined per stage in lifeStageConfig. Student gets 7 items, Mid-Career gets 8
  • "Explore more" — collapsible section containing every module NOT in the primary list. Items are visually muted but fully functional
  • Dynamic promotion — if a student adds a property, "Property" automatically moves from "Explore more" into the primary section
  • Active state — uses stage colour (violet for student, raspberry for mid-career) not a fixed colour
  • Collapsed sidebar mode — "Explore more" becomes a ⋯ icon that expands on hover
  • Mobile tab bar — maps the top 4 primary items to tabs, "More" tab shows the rest
