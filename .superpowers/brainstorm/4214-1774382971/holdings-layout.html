A: Inline Rows (Spreadsheet-style)

Compact grid rows within the form. Each holding is a row with all 4 fields visible. Quick data entry, minimal clicks. Headers shown subtly. Good for users adding 3-10 holdings.

B: Card List + Expand-to-Add

Added holdings show as compact summary cards. Clicking "+ Add Holding" expands a mini-form inline. Cleaner look, easier to scan, but more vertical space. Good for users who add 1-5 holdings.
