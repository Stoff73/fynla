Structured blocks, hybrid template semantics, save-from-article

How it works
  1. Article body is a JSON array of blocks, each with a type (heading, paragraph, image, etc.) and content
  2. Creating an article: pick "Blank" or a saved template → blocks copied in as a starting point → edit freely
  3. Saving as template: any admin can take a good article and click "Save as template" with a name
  4. Template reference kept on the article for filtering / analytics. If the template changes later, admin can "re-sync to latest" with a warning about overrides being lost
  5. No separate template designer — templates only come from articles
